# Task Tracer · 任务跟踪器

一个本地优先的个人任务工作台，用来记录、安排和回顾日常工作，无需账号。

[打开应用](https://todo.muquew.com/) · [下载发行包](https://todo.muquew.com/downloads/task-tracer-4.15.1.zip) · [English](README.md)

## 能做什么

- **快速记录：** 文本输入、描述、子任务和截止日期。
- **整理任务：** 项目、标签、搜索与保存视图。
- **安排日常：** 今日计划、重复任务、提醒和稍后提醒。
- **查看进展：** 列表、日历、时间线与近七天完成统计。
- **集中处理：** 批量操作、归档与撤销。
- **保护数据：** JSON 备份、导入预览、合并、恢复历史和 CSV 报表。
- **选择外观：** 四套主题、浅色／深色模式、中英文界面。
- **适应设备：** 响应式布局、键盘操作与离线 PWA。

## 开始使用

1. 点击顶栏 **添加任务**。旁边的箭头打开快速记录，例如 `明天 20:00 阅读 #学习 /个人`。
2. 用项目与标签整理任务，切换视图，或把任务加入 **今日计划**。
3. 在 **设置与数据 → 备份与迁移** 分别下载任务 JSON 和保存视图 JSON。

- 数据保存在当前浏览器中。清理站点数据或更换设备前，先在浏览器之外留存备份。
- 任务 JSON 用于恢复任务；保存视图需要单独导出。CSV 用于报表。
- 离线使用需先联网加载。安装与通知受浏览器、系统限制，不保证关闭应用后的提醒投递。

## 本地运行

在项目目录或发行包解压目录中执行：

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

打开 [localhost:8080](http://127.0.0.1:8080/)，无需构建或后端服务。
