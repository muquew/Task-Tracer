# 稳定交付说明 / Stable delivery guide

目标版本为 **4.15.1**，正在进行完整交付验收。目前线上已发布版本为 [4.15.0](releases/4.15.0.md)。本页在最终验收及发布完成后记录正式包、支持范围和实际结果，不提前把候选写成正式版。

产品是本地优先的个人任务工作台，范围包括任务捕获、安排、执行、回顾与本地数据保护。当前总目标与完成状态见 [GOAL.md](../GOAL.md)，产品用法见[中文说明](../README_zh_cn.md)／[English README](../README.md)。

## 完成交付的条件

| 范围 | 交付要求 |
| --- | --- |
| 记录与编辑 | 完整表单、快速记录、子任务、日期、标签、重复与提醒闭环；无效输入保留草稿并明确纠正，不能静默改变安排。 |
| 工作区 | 列表、日历、时间线、统计、搜索范围、保存视图、今日计划、批量与撤销结果一致。 |
| 数据 | 任务JSON、独立视图JSON、CSV各自用途明确；导入预览、冲突、快照、恢复、存储故障与并发保护可复核。 |
| 体验 | 中英文、四主题亮暗、桌面与窄屏、长内容、焦点、确认、错误与禁用状态实际审读。 |
| 工程 | 同一最终源码与工具输入完成完整登记检查、三引擎登记工作流、适用规模与无障碍范围。 |
| 发行 | 双构建、正式包载荷校验、解包持久／离线、实际上一版发行包升级／回退／再升级。 |
| 发布 | GitHub推送后核对域名资源／安全头，再实际操作并核对真实备份。 |

最终结果会绑定实际提交、源码／验证指纹、原始报告、正式ZIP及校验和；历史阶段和失败保留原身份，不能移用旧版本通过结论。

## 支持与能力范围

- 使用支持IndexedDB、现代JavaScript和原生日期／时间输入的浏览器。浏览器隐私或存储策略可能限制本地保存；应用会提供故障提示与可用的数据导出恢复入口。
- 任务位于当前浏览器资料中，没有账号或跨设备同步。换设备、清除站点数据、重装或降级前，分别保存任务JSON和视图JSON。
- 缓存完成后可离线加载；第一次使用需要联网完成应用壳缓存。安装方式依浏览器与系统支持，应用内提供相应说明。
- 提醒依赖浏览器权限、应用生命周期和系统策略。应用关闭后的系统闹钟式投递不在保证范围内。
- Linux浏览器引擎与模拟视口的通过结果，分别列实际范围；真实手机、软键盘、原生输入法、读屏、安装与系统通知的空白验收记录见[实机清单](manual-device-checklist.md)。

## 使用、备份和迁移

1. 在 [todo.muquew.com](https://todo.muquew.com/) 或可信静态部署中打开应用，使用顶部“添加任务”或旁边的快速记录。
2. 在“设置与数据 → 备份与迁移”下载任务JSON。实际检查文件已保存在浏览器之外；点击下载不等于已保留副本。
3. 保存的视图使用同页“迁移保存的视图”单独导出。任务备份不含视图、主题偏好或本地恢复历史；CSV是表格报表。
4. 在新的浏览器资料中先预览备份，明确选择合并或替换。替换前保存当前快照；有冲突时核对数量与保留方案。
5. 本地恢复历史与任务共享浏览器存储，不能替代独立备份。发现问题时先保存副本，再依据恢复预览操作。

## 更新、构建与回退

- 应用内“设置与数据 → 帮助与关于 → 检查更新”提供主动检查。处理未保存输入与草稿后，等待新版本准备好再刷新；升级后关闭或刷新旧窗口。
- 开发环境与完整检查命令见[贡献指南](../CONTRIBUTING.md)。`python tools/build_release.py`生成静态ZIP及校验和，不会自动发布。
- 自行部署时使用HTTPS或本地可信来源，保留包内service worker、语言、图标、manifest和部署安全头配置，见[发行说明](distribution_zh_cn.md)／[distribution guide](distribution.md)。
- 回退前导出任务及视图、处理草稿并关闭旧窗口。恢复上一份完整静态包，重新打开后核对数据；不要通过清站点数据回退。只将已经验证的版本／格式组合视为兼容。

正式包名称、SHA-256、提交与实际升级基线会在验收完成后补入本页和[4.15.1发布记录](releases/4.15.1.md)。
