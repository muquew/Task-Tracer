## 使用、备份与更新

1. 从 [todo.muquew.com](https://todo.muquew.com/) 或可信静态部署打开应用，使用顶部“添加任务”或旁边的快速记录。
2. 在“设置与数据 → 备份与迁移”下载任务JSON，并确认副本已保存在浏览器之外。视图JSON使用“迁移保存的视图”单独导出；CSV用于表格报表。
3. 换设备、清理站点、重装或降级前先导出任务与视图。导入时核对预览数量，明确选择合并或替换；替换前保存当前快照。
4. 本地恢复历史与任务共用浏览器存储，不能替代外部备份。出现异常时先保留副本，再按恢复预览操作。
5. 在“帮助与关于”主动检查更新；先处理未保存输入与草稿，待版本准备好后刷新。升级或回退后关闭／刷新旧窗口并核对数据，勿用清站点数据代替回退。

原 **4.15.0** 干净发行包仍保留：990,442字节／24文件，SHA-256 `02cc67c9ac2a454b9ca248c3a122f92060c674677914dfab567cd7de5f6fbca3`。它来自原提交 `93c990012deaf8556517cbc5995dfebfd2a2a952`，没有用新代码重建旧版本。
