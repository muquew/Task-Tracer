# 4.14.0：任务面板与全站操作优化

任务表单原先以连续字段承载内容、属性和安排，日期依赖功能不易发现，临时关闭选项还可能清掉输入。本轮将桌面面板扩至最大920px，内容与子任务居左，项目、日期和直接可填的标签居右；“提醒与重复”在两栏下方按需展开，手机按自然顺序单列。“今天”“明天”“选择”提供正向日期入口，同时保留原生“无截止日期”勾选和项目名称建议。方向见[主动审查任务书](../../PROACTIVE_BRIEF.md)。

## 操作与数据修正

- 临时禁用日期、提醒或重复字段保留表单原输入，提交时才按最终安排归一。指定星期首次可预选周一／三／五；清空所选星期后，保存会就地提示至少一天，并将错误显示在操作栏上方，不静默补回规则。
- 删除其他子任务时，以稳定ID保留当前行内编辑的原始文字、光标和选择范围。主保存继续收纳尚未点“＋”的子任务文字。
- “选择”直接出现在筛选旁，批量“更多操作”使用浮层，保留当前范围与选中对象；窄屏统计的三个工作入口改为逐行显示，去掉重复提示。
- 浅深色与界面语言移到主题图库之前；任务维护统一标题与数量状态，存储入口、卡片和弹窗统一命名。导入明确呈现合并／替换原生单选项，默认替换及既有快照、二次确认与风险保护保持。恢复点预览默认折叠，未勾选替换确认时恢复按钮禁用，切换恢复点重置勾选。
