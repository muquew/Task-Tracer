# Task Tracer 4.10.0 — 常驻导航与独立设置

2026-10-25（北京时间）：常驻导航与独立设置已实现并部署。完整工程基线及单项测试导航补验已完成；真实域名复验随后发现动态备份状态的语言遗漏，已由[4.10.1](4.10.1.md)修复并完成最终发布验收。原始失败、中止和补验记录均保留。

## 本版范围

- 列表、日历、时间线、统计移入桌面常驻侧栏与窄屏底栏，四项均显示图标和名称；搜索／筛选工具的折叠不再控制视图入口。
- “设置与数据”使用独立工作区，按外观与语言、备份与恢复、提醒与安装、任务清理、帮助与应用信息组织现有功能。顶栏和侧栏均可进入，`Ctrl/Cmd + M`打开设置；“返回任务”与四视图导航回到任务工作区。
- 保留原任务区及搜索、筛选、草稿和批量选择状态，保留原备份、导入、恢复、数据安全、通知、安装、保存视图迁移、帮助和清理能力及其保护逻辑。
- 检查新增／编辑、任务操作、批量操作、导入预览、恢复历史、视图迁移、存储安全、安装、帮助和诊断的组件与说明，使它们与主工作区使用同一套界面语言。
- 帮助中的今日计划说明对应真实“任务操作 → 加入今日计划”路径；任务清理明确作用于整个工作区内已完成且未归档的任务，不受当前项目、搜索或筛选影响。
- 修复子任务编辑时延迟初始化光标覆盖用户选区、导致快速替换可能拼接旧文字的问题；输入挂载后同步设置初始焦点。保存视图按钮的可访问名称与可见文字一致。
- 恢复未保存草稿时，先恢复所有字段、控件及草稿队列，再恢复子任务行内编辑焦点，避免程序化切回任务名称导致提前提交、裁去原始空格。首次跨引擎跑批拦下该回归后中止，原生失败及中止记录保留，不计作通过。

设计规则见[DESIGN.md](../../DESIGN.md)，当前队列见[GOAL.md](../../GOAL.md)，操作说明见[中文README](../../README_zh_cn.md)及[English README](../../README.md)。
