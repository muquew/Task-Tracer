# 4.11.0 全站使用体验整理

本轮从实际浏览器使用开始，覆盖任务工作区、添加与编辑、项目与保存视图、设置、备份迁移、恢复、安全、帮助和诊断。沿用已认可的颜色与组件语言，重点解决操作位置、信息层级及页面之间的衔接。应用、缓存及 npm 版本为4.11.0，语言资源4.39；数据库2、任务备份JSON2.4和视图1.1/1.0导入保持兼容。

## 使用上的变化

- 顶部保留一个稳定的全局添加入口，按需展开快速记录。四视图不再各自常驻底部输入框；解析出的日期、星期、项目和标签可在保存前核对。“更多选项”带入完整表单，取消保留原文，成功保存清理关联草稿。
- 语言与外观统一放入设置。设置采用五个实际分类面板，保留当前分类与任务返回上下文；备份、导入和恢复优先，其他数据工具分级呈现。帮助先提供常用操作和快捷键，细则按需展开，诊断也有直接入口。
- 各视图有自己的标题，切换回到页首；统计收起无意义的状态筛选、排序和批量工具。手机月历为紧凑月份与可读日程，统计在窄屏保持可扫描的密度。空工作区也可使用月历，并看到明确的零统计。
- 完整表单先展示名称、描述、项目、日期和子任务；提醒、重复与标签放在“更多设置”，已有高级值会自动展开。批量先选择任务再显示动作；保存视图优先展示名称；搜索无结果可直接清除条件。
- 手机搜索与按钮分行，保留完整标签；撤销文字、反馈位置、单按钮弹窗页脚和方向键导航一并调整。

实际使用中额外发现并修复：中文星期日期被静默按今天保存、取消空白日历添加后旧日期串入普通新增、翻月后的日程仍指向今天、清除筛选后摘要滞后，以及空记录进入完整表单时默认值与预览不一致。
