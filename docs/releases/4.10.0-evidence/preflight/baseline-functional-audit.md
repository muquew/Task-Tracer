## 本轮建议

1. **优先：完成一级视图导航与独立设置工作区。** 01/07/26显示四视图被嵌在工具区、移动端只有图标，数据/安装/通知/清理/帮助挤在同一窄菜单。这是发现性问题，不是能力删除。父任务正在处理。
2. **P2：同步中英帮助中的实际路径。** 16/22/28仍说展开快速添加与筛选工具、任务上的靶心按钮。改为列表底部快速添加、任务更多 → 加入今日计划；新设置页落地后，同步备份、视图迁移和安装路径。
3. **P2：恢复批量删除的危险样式。** 06/26中删除与一般secondary按钮同灰；04任务更多里的删除则为红色。冻结源码188行`.batch-danger`被673行`.btn-secondary`覆盖。建议使用更具体的危险variant并覆盖hover/focus，保留现有确认保护。
4. **P2：把通知真实权限状态放到设置中。** 此次真实隔离profile的诊断18显示permission=denied，而07仍只写开启通知。区分应用偏好与浏览器授权，blocked时给浏览器设置指引。该观察不代表所有用户均被拒绝，也不是提醒逻辑丢失。
5. **P3：按窗口目的统一退出动作。** 14视图迁移管理、16/22/31/34只读帮助显示取消+关闭；19只读安装说明显示取消+确认。只读说明应有单一明确的关闭动作，避免暗示会提交更改。导入和恢复的取消保护须继续保留。
6. **后续细化：收束高级说明的密度。** 02/20/24/33中标签引用与时钟跳变的说明常驻，移动端占据较多首屏。可提供简短概要加详细说明入口，但这属于阅读密度优化，不能移除时间/提醒的真实限制。
