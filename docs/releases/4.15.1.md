# 4.15.1 稳定交付候选

本版本正在完成整个本地优先任务产品的稳定交付验收。当前实现修复完整任务表单在空截止日期、空自定义重复间隔时静默清除或改变安排的问题；保留原始输入并显示明确错误。快速日期补齐昨天／昨日／yesterday／前天，保留只填时间的默认当天行为。放弃编辑和保存状态恢复独立内边距，可撤销的任务删除使用准确文案。

多项目、状态和排序菜单会根据可用屏幕空间向上或向下展开，并在桌面与窄屏切换后重新定位；长菜单独立滚动。Firefox 中按下按钮期间的自动聚焦滚动不再移动点击目标，键盘聚焦和表单可见性保持。实际不可撤销的恢复历史清理使用危险操作样式，与可撤销的任务删除区分。

完整带分页负载的无障碍检查发现，日历详情按钮的显式名称漏掉了可见时间；现使用时间、任务名和状态组成的原生名称，使语音定位与可见内容一致。原始失败以及在修复前中断的验收保留原身份，修复后的整体验收另行记录。

应用、缓存与 npm 为4.15.1，语言资源4.45。保留四套完整主题、亮暗模式、常驻视图导航、独立设置、单一主添加入口及既有任务／数据能力。宣传截图从最终源码的真实中英文界面重新拍摄。

本轮新鲜亲用覆盖工作区、编辑／捕获、五类设置与真实数据操作。完整登记检查、三引擎工作流、最终发行和域名复验尚在执行，结果将在真正完成后绑定具体输入与工件，不借用4.15.0的局部通过结论。

当前总目标见 [GOAL.md](../../GOAL.md)，最终交付入口为[稳定交付说明](../stable-delivery.md)。价格、收款和正式商业条款保持待定，许可及DB2／任务JSON2.4／视图1.1与1.0导入兼容不变。
