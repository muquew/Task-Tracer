# 4.4 candidate notes

This is a working-tree candidate, not a published production release. It continues the local-first buyout/professional direction; it adds no purchase server or account requirement. The public license remains unchanged.

## Changes

- Main-menu CSV reporting exports all stored tasks, including completed and archived tasks, independently of search and filters. UTF-8 BOM, quoted cells, escaped quotes and CRLF support Chinese and multiline values. Tags, repeat weekdays and subtasks use JSON cells. Formula-like values receive a leading apostrophe, including leading whitespace/BOM cases.
- The 17 stable columns are `id`, `name`, `description`, `project`, `tags`, `status`, `due_at`, `due_local_date`, `due_local_time`, `due_time_zone`, `completed_at`, `created_at`, `repeat_type`, `repeat_interval`, `repeat_weekdays`, `repeat_paused`, `subtasks`.
- CSV is a report rather than a restorable backup: it does not update the last-JSON-backup timestamp. Continue using JSON for full restoration. Formula neutralization changes the reported text intentionally; spreadsheet edits/re-saves may remove the protection.
- Delayed reminder delivery now rereads and patches the latest task inside a transaction. It checks the captured reminder key, snooze and last-delivery timestamp before updating only reminder metadata. It skips deleted, completed, archived or changed reminder conditions. This preserves newer edits and avoids resurrecting deleted records or clearing a newer snooze.
- A new two-window regression first reproduced an overwrite when a notification awaited native delivery and the original window refreshed before completing. It now covers editing, deletion and snoozing. CSV tests inspect actual downloaded bytes, parsed cells, task immutability and backup-timestamp isolation, plus empty-workspace output. Keyboard navigation includes the new menu item.
- The unified suite now registers 16 programs. The browser CI matrix also runs CSV checks in each engine.

## Compatibility and validation

App/cache 4.4; translation resources 4.28. IndexedDB stays version 2 and JSON export version 2.4. Existing recovery, undo, import/export and offline checks remain in the full suite. Refresh older windows before editing after an upgrade; pre-revision-aware clients cannot be assumed to honor current conflict protection.

The unified command is `TASK_TRACER_BROWSER_EXECUTABLE=/usr/bin/chromium python3 tools/check.py --report dist/check-results-4.4.json`. Final integrated outcomes and the artifact checksum are recorded below. The previous [4.3 evidence](4.3.md) remains historical. The production domain is a supplementary deployment check; local validation does not depend on publishing or on that domain being reachable. Real-device Safari/iOS installation and operating-system notification delivery still need manual verification before a commercial release.
