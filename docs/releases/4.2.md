# 4.2 candidate notes

Superseded by the ongoing [4.3 working-tree candidate](4.3.md); these notes preserve the earlier local validation record.

Prepared on 2026-10-22. This describes the current development candidate; it is not a published release or a commercial license grant.

## Changes

- **Recovery history:** restore a dated task checkpoint from the app menu after explicitly confirming replacement. Keep up to 10 local checkpoints, including empty lists. Save before the first write, after five-minute write intervals, and before deletion, import/merge, undo, and restoration. Checkpoint and task changes use one transaction.
- **Concurrent-edit protection:** refuse stale writes from other tabs, refresh the task list, and preserve an obsolete edit-form draft for copying. Require reopening the latest task before saving. Undo checks the affected tasks and preserves unrelated newer tasks.
- **Development quality:** pin browser-test dependencies, provide `tools/check.py`, configure GitHub Actions, and check PWA installability in a regular browser profile.
- **Maintenance:** document contributing, security boundaries, local recovery, and release gates in both README entry points.

Recovery history stores task snapshots in the same browser as the tasks. It is not an external backup, encryption, or cloud sync. Export a separate copy before changing devices or clearing browser data.

## Compatibility and upgrade

The app/cache version is 4.2 and language resource version is 4.26. IndexedDB remains version 2; recovery history and task revisions are stored in the existing config store. The task export version remains 2.4. No account or application backend is introduced.

Export existing tasks before upgrading. Close or refresh all older pre-4.2 tabs, including offline app windows, before editing after the upgrade. The revision protocol protects cooperating 4.2 clients; older cached clients do not increment `taskRevision` and cannot be assumed to honor the new guards. Test update and rollback behavior with realistic synthetic data before deploying. A deployed rollback and data restoration have not been validated by these local checks.
