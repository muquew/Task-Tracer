# 4.13.1 一键添加与主动检查更新

主“添加任务”原先先展开快速记录，再经“更多选项”进入完整表单；应用更新主要依赖被动提示。本补丁将完整添加放回主操作，并在设置中提供可主动查询的更新状态。

实现、实际审读、相关保护检查及发布/真实域名复验均已完成。4.13.0的已发布主题及组件记录保留原身份，不作为本补丁通过证明。

## 操作变化

- 顶栏“添加任务”直接打开完整表单；旁边“快速记录”箭头保留轻量解析和预览。已有未提交的快速记录文字时，主按钮接续文字与解析上下文；`Ctrl/Cmd + I` 保持独立新增。“完整表单”仍是快速记录进入完整表单的可选路径。

- 新建完整表单与快速记录继承当前明确项目；无项目范围保持无项目，“全部项目”才默认Inbox，显式`/项目`优先。当前今日计划内创建会加入该计划，截止日期不受影响。
- 今日计划已有任务但搜索无匹配时，显示真实空结果与清条件入口，恢复结果后仍留在计划。320px等最窄布局的撤销使用图标并保留可访问名称，避免文字竖排。
- “设置与数据 → 帮助与关于 → 检查更新”主动检查，分别呈现检查中、最新、准备就绪、离线、不支持和失败状态。更新准备好后显示“刷新更新”，关闭被动提示后仍可从设置查看。
- 检查会等待正在安装的worker到达可用状态；应用准备好的更新时等待控制器切换，不再依赖700ms固定延时强刷。失败保留当前页面和可重试状态。
- 刷新前检查快速记录、表单更改、待恢复草稿和保存中的任务操作，未处理时提示先保存或解决输入。确认更新后仍再次检查，避免等待接管期间新增输入被刷新带走。

应用／缓存／npm为4.13.1，资源4.42；数据库2、任务JSON2.4、视图1.1及1.0导入兼容保持。既有主题、任务、备份和离线边界不变。
