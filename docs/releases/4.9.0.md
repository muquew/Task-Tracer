# Task Tracer 4.9.0 — 界面重设计候选

记录日期：2026-10-25（北京时间）。状态：**实现与验证进行中，尚未发布**。最近已完成发布的版本为 [4.8.6](4.8.6.md)；该版本的通过记录保留原有范围，不作为4.9.0已通过的证明。

## 目标与变化

本次重新组织个人任务工作区，使任务、项目、日程与偏好更容易找到，同时形成一致的浅深主题、组件层次和中英文文案。

- 项目和保存的视图进入侧栏；窄屏提供可展开的导航。全部任务、手动今日计划与项目范围继续保留各自语义。
- 顶部提供独立语言入口，以及浅色、深色、跟随系统三种外观偏好。跟随系统响应当前窗口的系统配色；显示主题与保存的偏好分开处理。
- 任务采用统一的完成、描述、项目、日期和子任务层次；次要动作收拢到任务操作菜单，保留原有编辑、提醒、重复、归档和删除能力。
- 未来7天索引、小月历与窄屏日程入口复用原有日历日期路由。打开日期改变查看位置，不修改任务期限，也不把“今天截止”自动加入手动今日计划。
- 中英文文案统一操作名称、提示与保存的视图用词，并为数量消息提供单数形式。用户写入的任务、项目、标签与描述不随界面语言改写。
- 新图标使用 Tabler Icons；[第三方声明](../../THIRD_PARTY_NOTICES.md)保留其来源和 MIT 许可。项目 [LICENSE](../../LICENSE)保持原文。

## 数据与发行边界

候选应用、缓存和 npm 版本为4.9.0，语言资源版本为4.37。数据库继续使用版本2，任务备份继续使用 JSON2.4，视图文件继续为1.1并兼容1.0导入。

界面重设计保留重复链、提醒、分页、全量批量选择、手动排序、撤销、存储故障处理、未保存草稿、备份恢复与离线更新逻辑。独立设计样板使用过的简化任务模型不构成生产实现或数据迁移。

发行白名单已包含第三方声明，当前契约为23个来源文件与生成的 `integrity.json`，即24个发行文件。该数量描述打包契约，不表示已经生成或验收最终 ZIP。源提交、源码与验证输入指纹、ZIP 校验和及实际部署记录均待最终候选稳定后登记。
