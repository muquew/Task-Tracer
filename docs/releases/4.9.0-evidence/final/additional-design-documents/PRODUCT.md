# Task Tracer

Task Tracer 是本地优先的个人任务工作区，面向希望直接管理日常事项、项目与重复任务的个人用户。主要使用场景是桌面浏览器与窄屏浏览器，也可在支持的环境安装为 PWA。

核心流程是捕获任务、安排与筛选、执行、回顾、备份并恢复。用户无需账号或服务器即可使用；现有数据的导出恢复不依赖购买、登录或在线服务。

## 产品事实

- 支持任务、子任务、描述、项目、标签、截止日期时间、无日期任务、重复与提醒。
- 手动今日计划是用户主动挑选的集合，独立于截止今天；项目、保存视图、状态筛选和搜索可以组合。
- 列表、日历、时间线与统计呈现同一份真实任务数据。分页、批量全量选择、手动排序、归档与撤销是现有能力。
- 数据位于当前浏览器配置的本地存储，可能受到隐私设置、配额、清除站点数据或驱逐影响。本地恢复历史与任务共享存储，不能替代独立 JSON 备份。
- 任务备份、CSV 报表、保存视图迁移和内存草稿下载用途不同，文案与操作须准确区分。下载已开始不等于文件已经保存。
- 离线依赖应用壳已被缓存。提醒依赖浏览器、操作系统、权限与应用生命周期，不能承诺应用关闭后的系统闹钟能力。
- 中英文、键盘、输入法组合输入、焦点与未保存草稿属于核心使用能力。主题变化不应改变任务数据或中断当前输入。
