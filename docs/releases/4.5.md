# 4.5 candidate notes

This working-tree candidate continues the local-first commercial product objective. A candidate number is a checkpoint, not a new approval phase. It is not a published release or a purchase offer. No payment server, account requirement or commercial license terms are introduced.

## User-facing changes

- Fresh workspaces start empty and stay empty on reload. Users can explicitly add three clearly labeled example tasks from the empty state, then edit, delete or undo them. Examples issue no notifications. Duplicate clicks, a newer task in another window and quota failure cannot overwrite existing tasks or leave partial examples.
- Help and support are available from the menu and footer. The guide explains capture, search syntax, saved views, JSON/CSV, installation/offline behavior, browser reminder limits and shortcuts. A visible action opens the existing command palette.
- Diagnostics show a reviewable local JSON preview before an explicit download. The report includes application/browser versions, capability flags, storage status and whether a service worker controls the page. It excludes task contents, views, preferences, URLs and detailed error messages. Nothing is sent automatically. Startup storage failures retain Help, diagnostics and keyboard/modal controls; closing Help while native storage queries are pending does not reopen it later.
- JSON scope is explicit: task data, including subtasks, tags, schedules and Today Plan markers, is restorable; app preferences, saved views and recovery history are excluded. CSV remains reporting only.
- Bilingual GitHub issue forms collect minimal reproduction and browser information with synthetic data. Support and security guidance avoid requesting personal backups in public reports.

## Data correctness

- Nullable imported recurrence links no longer become ID zero. Numeric zero and numeric-string zero remain valid references; blank, boolean and nonfinite values remain absent.
- Import reserves all valid source IDs before generating replacements for invalid or duplicate IDs. Invalid IDs cannot steal a later valid zero or falsely make its references ambiguous.
- An unrelated ID-zero task no longer suppresses recurrence, and later occurrences preserve root ID zero. A previously corrupted self-link can resume recurrence instead of blocking the next occurrence. Real-browser regression covers generations, reload and JSON round-trip.
- Saving or deleting a saved view reads and changes the latest list inside a single config transaction. Only committed lists update memory. Stale windows preserve unrelated additions/deletions, while an aborted save retains the draft without leaking a phantom view into a later save.
- Desktop notifications no longer cover the header menu. They appear at the lower left; informational text does not intercept clicks and the Undo action remains interactive. A real-coordinate regression reproduced header obstruction before the fix and now passes at 1280px and 900px.
- Essential event handlers bind once in normal and storage-failure startup paths, preserving Help/dialog access and avoiding duplicate handlers.
