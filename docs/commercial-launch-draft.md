## 商品页正文草稿

**Task Tracer 4.8.5 · 本地优先的离线任务工作台（候选文案）**

不用注册账号，在自己的浏览器里记录任务、安排今天、管理重复事项，并通过日历、时间线和统计回顾进展。首次联网打开并缓存应用后，可以离线使用；浏览器支持时可安装为独立窗口。

- 快速添加、项目与标签、子任务、今日计划和批量操作，让记录与执行连贯起来。
- 保存搜索、筛选、排序和视图，重复打开常用工作范围；视图可通过独立 JSON 文件迁移。
- 任务 JSON 用于备份恢复，CSV 用于表格报表。迁移设备时，任务与保存视图分别导出。
- 同一浏览器保留最多 10 个任务恢复点，可分页预览、单独导出或确认清空本地历史；多窗口冲突保护、导入预览和替换前快照帮助减少误覆盖。
- 导入任务只改需要的字段，保留未修改的文本和已有提醒值；完整表单可用双引号保留标签中的逗号。
- 编辑逾期任务或补记过去的截止日期；仅修改名称、描述时保留原截止时间点与时区。
- 表单退出前可继续编辑或放弃；存储故障后的草稿仅留在当前页内存，可单独下载供查阅，刷新前需另存。
- 快速添加存储失败时保留可选中复制的只读原文；有未保存文字时在原页面重试，恢复后明确提交一次，不自动重放。它不包含在表单草稿下载中，刷新前仍需复制。

**使用范围与限制：**任务保存在当前浏览器配置中，应用不提供账号云同步。清理网站数据、丢失设备或更换域名可能丢失本地内容，请另存备份。JSON、视图和草稿文件不加密，可能包含私密内容；草稿文件不能作为任务备份导入，刷新或关闭页面会丢失内存草稿。发起下载不保证文件已保存，需检查实际文件。浏览器提醒需要授权，受系统与应用生命周期影响，不能保证关闭应用后送达。网址捕获内容可能出现在浏览器历史或托管请求日志中。

## 手动交付流程

以下为验证与商业条款齐备后的交付流程草稿，目前不执行收款或销售。

1. 以已完成五项GOAL验收的本版文件为工程交付基线，核对[候选记录](releases/4.8.5.md)及[来源记录](releases/inputs-4.8.5.json)中的完整检查、三引擎、规模/性能、构建/离线/升级与原始失败，确认ZIP、sidecar、SHA及`integrity.json`身份。正式商业交付位置由版权方提供；此步骤不启动收款或发布。
2. 按已公布的价格与条款形成订单。确认买方、允许用途、版本、席位/设备范围、更新权益和分发限制，再由 muquew 出具相应授权。收款凭据与授权材料单独保存；静态程序中不存放支付或签名密钥。
3. 交付上述 ZIP、校验文件、适用的商业授权和购买凭据，并附[使用与恢复说明](../SUPPORT.md)、[安全报告说明](../SECURITY.md)及本版本记录。当前未设置结账页或商业激活服务。
4. 指导买方把整包部署在稳定的独立 HTTPS 地址；本地评估可解压后运行静态服务器。直接双击 HTML 不是受支持的 PWA 安装方式。改变地址或浏览器前，先分别导出任务与视图。
5. 用示例任务验收：添加、重复任务、刷新保留、首次缓存后的离线打开、JSON 恢复与视图迁移。在 4.7 或更新版本中修改保存视图前，关闭或刷新所有 4.7 之前的旧窗口，它们可能把新项目范围解释为全部项目；降级前另存视图 1.1 文件，回到 4.7 或更新版本后才能导入。保存本次与上一版的发行文件和验证记录。
6. 普通问题按 [SUPPORT.md](../SUPPORT.md) 收集版本和示例复现；疑似漏洞按 [SECURITY.md](../SECURITY.md) 的私密报告指引处理。公开反馈不要求买方上传个人任务或视图文件。
