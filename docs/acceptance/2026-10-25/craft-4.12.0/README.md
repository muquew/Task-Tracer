## 亲用覆盖

基线以真实快速记录/表单、菜单和设置检查任务创建编辑、子任务、重复暂停/恢复/跳过、今日计划、项目与保存视图、搜索筛选、单条/批量处理、列表/日历/时间线/统计、五类设置、通知/安装说明、备份导入恢复、CSV、视图迁移、存储安全、维护和帮助诊断。

候选初轮再次操作完成→归档→统计、四种强调色与亮暗切换、批量移项目/空输入/撤销、保存视图更新、稍后提醒、具名删除取消、下载/合并/替换/恢复预览、视图导出和重复导入、零候选维护、手机帮助。检查发现的趋势标签、统计返回、选中数量、通知语义、焦点和手机通知覆盖问题集中修复。
