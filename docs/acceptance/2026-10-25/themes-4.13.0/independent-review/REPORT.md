# 2. Screenshot-grounded strengths

- **整体 palette 已经改变，而非只换按钮色。** 对照基线 `audit/01-iris-light-list.png`、`audit/04-ocean-light-appearance.png`，`07-component-workspace.png` 的深墨紫导航、冷紫工作台、浅色任务面、分组条与标题区形成了新底色体系；`17-ocean-list-components.png` 同时改变导航、画布、工具栏、任务面、日历与前景文字的色温。海湾主题不是在原白页上换一个蓝按钮。
- **组件已有不同角色。** `07` 的任务内容面比工作台明亮，分组条略沉，右侧辅助日程独立但安静；`08-component-menu.png` 的菜单比底层内容更亮，有可辨识的浮层与删除分隔；`09-component-editor.png` 的标题/操作带、输入面、已添加子任务行、焦点描边各有区分。无需用纹理或插画填空。
- **核心任务仍占主要版面。** `07`、`17` 在 1440 宽画面内呈现五条任务、描述、子任务入口、日历与到期列表；截止信息靠右形成可扫读列。相比基线，画面不再由一片近白背景和白卡主导，也未为了质感加入营销式大图。
- **材质语言跨视图连贯。** `11-component-statistics.png` 的连续状态条与两列回顾、`12-component-calendar.png` 的月份工具栏/星期带/日期格、`14-component-gallery.png` 的主题选择卡和普通下拉框，沿用同一前景、分隔线和面层关系。日历的逾期/临期任务仍保留独立语义色。
- **窄屏已有结构变化。** `22-component-mobile-list.png` 改为竖排截止与描述、紧凑日程摘要、底部导航；`30-component-320-timeline-clock.png` 中长任务名、日期和时间可以换行，仍留有完成圈与菜单位置。`31-component-dark-drawer.png` 的导航文字和层级清晰；`35-component-320-editor.png` 将日期与时间纵排，主要保存操作在画面内。已见画面中没有明显横向溢出。

# 3. Material findings（按优先级）

1. **P2 — 深色导航中的少数次要图标像被禁用。** `07-component-workspace.png` 左侧“今日计划”的绿色靶心与“保存的视图”的紫色书签明显比旁边的标签更暗，后者尤其接近导航底色；`17-ocean-list-components.png` 的同一靶心、蓝色书签也有相同问题。其他导航图标清楚可读，因此这两处显得像未启用的功能，破坏组件一致性。`31` 的深绿抽屉书签已有较亮前景，说明不必改变整个侧栏就能解决。此处是 PNG 中的可辨识度判断，未声称已测得 WCAG 数值。

2. **P2 — 统计中的数据条退到了分隔线层级。** `11-component-statistics.png` 右侧“按项目安排待办”两根表示 3 项/2 项的水平条很淡，与面板及细分隔线接近；左侧七日图的实色柱却很清楚。结果是同屏中一种数据图形强、另一种像骨架/底线，读者更多依赖右上文字才能知道它是数量编码。应提升实际数据段的可见度，同时保留中性的辅助轨道；无需给整张统计卡增加阴影或装饰。

3. **P2 — 320 编辑器的更多设置刚好落在固定底栏切口。** `35-component-320-editor.png` 中“More settings”位于操作栏上缘，后续表单内容在这张截图中不可见；`09-component-editor.png` 桌面编辑器的标签帮助文也紧贴操作栏被截断。静图不能证明内容被永久遮挡，但目前呈现出来的末端是半截内容，而非一个干净的表单边界。需要确认滚动区域末端具有足够留白，最后一个字段、说明和展开入口能完整滚入视口。这是需验证的具体疑点，不据此声称表单功能失效。

# 4. One-batch correction constraints

- 只修导航前景 token：默认“今日计划”“保存的视图”图标使用可辨认的侧栏次要前景或在该底色上成立的语义色，保留当前选中项和导航密度；不要把所有未选中项染成主强调色。
- 将统计项目条的数据段提升到明确的数据前景层级；分隔线/轨道继续保持更轻。保留 3:2 长度关系、数值和项目标签，不新增图表装饰。
- 核对编辑器滚动内容末端的 padding/scroll-padding，使最后的展开项、字段和帮助文能完整停在操作栏上方；仅在实际需要时修正，不因截图处于中间滚动位置而重写编辑器。
- 保留已成立的整套 palette、桌面两栏任务布局、窄屏底部导航与表单结构。不要为填满空处新增卡片、插画、渐变或常驻阴影，也不改变任何任务数据、备份协议和现有能力。
