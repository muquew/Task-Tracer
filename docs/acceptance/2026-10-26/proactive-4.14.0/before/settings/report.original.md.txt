## 应保留的边界与限制

备份含归档任务但不含视图/偏好/恢复历史；CSV不能恢复；视图文件可能含私密搜索词，单独导出。恢复点与任务共用浏览器存储、清站点数据会丢失、可能保留已删内容；清空历史不可撤销。诊断的完整预览、报告包含/排除字段、自行下载与“不自动发送”都应保留。通知/离线使用的浏览器与应用生命周期限制、更新前未保存内容保护也不应当作冗余删除。

截图可确认本轮画面和层级，不能据此声称全 WCAG、真实读屏、实机软键盘/IME、OS 安装/通知、全浏览器、规模或所有恢复冲突通过。没有打开 GitHub 发消息。会话无 page error；一次操作脚本误用旧 `#modal` 定位器导致 Escape 超时，之后用实际关闭按钮继续，原错误保留于会话报告，不归为产品缺陷。捕获 JSON 中旧 `dialog` 便利字段未用于判断弹窗；以 PNG 和逐步 ARIA 文本为准。
