# 功能价值、完整性与界面质感审查

本轮针对4.11.1实际界面进行新审查，再实现4.12.0候选。用户所说的“审批”已明确为对现有功能与界面的审核批判。判断标准是：帮助完成什么事、入口和结果是否清楚、数据口径是否可信，以及能否自然进入下一步。

本文件记录基线发现、取舍和整改复核。候选已在全新浏览器资料中亲用，证据见[本轮画面与操作记录](acceptance/2026-10-25/craft-4.12.0/README.md)；工程保护与发布状态见[4.12.0记录](releases/4.12.0.md)。截图均来自本轮真实浏览器，不使用以前的测试通过数证明本轮功能价值。

## 逐页与能力判断

| 页面或能力 | 用户用途及本轮检查 | 基线判断与整改方向 |
| --- | --- | --- |
| 空白工作区与快速记录 | 真实创建有期限/无期限、不同项目与标签的合成任务 | 单一全局入口有价值，保留解析预览、Inbox落点和原始文字。补充批量归类出口。 |
| 完整新增/编辑器 | 实际编辑描述、日期、项目、标签及已有高级值，取消与放弃更改 | 功能字段足够，常用/高级分层合理；焦点双框、重描边和灰遮罩需打磨。 |
| 子任务 | 真实添加、展开及勾选 | 能拆分执行步骤，保留父子关系和完成状态；与批量选择使用方形语义。 |
| 重复任务 | 每日任务完成、暂停/恢复、跳过本次 | 例行事项闭环有用。后继继承今日计划是实证缺陷，须清理新一期的手动计划日期。 |
| 提醒与稍后提醒 | 真正设置十分钟后提醒，查看任务与设置说明 | 提醒配置有用途；需持续展示具体时间及通知未开启状态，避免仅一条成功toast。原生系统投递未验证。 |
| 任务菜单与归档 | 实际归档未完成项、归档筛选、恢复、删除取消/执行及撤销 | 单条与批量规则应一致；归档作为移出日常列表保留记录的操作，两处均可用。删除须具名和明确动作。 |
| 今日计划 | 主动加入任务，完成重复事项，查看计划进度 | 手动挑选与今天截止是两种用途，应继续区分。修复生成下一期后计划分母自动增加。 |
| 项目与Inbox整理 | 项目筛选与逐条改项目，批量归档 | 范围导航有用，但收集后逐条整理费力。补批量移到项目，复用原子写入与撤销。 |
| 搜索/筛选/排序 | 当前条件、无结果、状态与项目范围、手动顺序 | 能缩小实际工作集合；新增统计入口必须保留已有搜索交集，不能仅改一个被搜索覆盖的筛选字段。 |
| 保存的视图 | 创建、同条件再次保存、名称更新、删除 | 保存常用条件有价值。相同条件的去重应明确为更新并预填已有名称，不再暗中改名。 |
| 批量处理 | 手机0选择/有选择、归档和恢复 | 全量选择和执行有用；完成优先，其他操作集中到有文字的更多入口，避免动作面板挤走对象。 |
| 列表 | 实际任务扫描、菜单、完成与编辑 | 适合逐项执行；未来临近截止与真正逾期应有不同视觉语义。 |
| 日历/当日日程 | 实际空月历、已有日期任务、选日及添加 | 适合按截止日期安排工作；保留手机紧凑月份与可读日程。 |
| 时间线 | 实际查看按日期分组的有期限任务与无期限区域 | 提供跨日顺序，区别于月历的空间规划；保留真实日期顺序和任务操作。 |
| 统计与回顾 | 真实完成、归档、撤销后比较指标；项目范围与返回任务 | 正常归档不应抹掉成果。主区改为逾期/今天截止/无日期待办入口；回顾含归档完成记录，趋势显示日期与数量，项目数量可进入对应任务。 |
| 外观与语言 | 实际切换中英文、浅色/深色 | 本地个人偏好有价值。增加独立强调色，并统一亮暗表面、焦点和浮层层级。 |
| 备份、导入与冲突 | 真下载JSON，合并全跳过，下载替换前快照后执行替换 | 是本地优先产品的重要保护。模式、实际新增/跳过/替换影响与动作应在决策前清楚呈现，成功检查可折叠。 |
| 本地恢复与CSV | 当前3任务恢复为2任务，再核对CSV实际2行 | 能撤回错误写入；补当前→目标对照与明确恢复动作。CSV是报表，不等同完整JSON备份。 |
| 保存视图迁移 | 真创建/导出/导入同文件，实际0新增/1重复 | 便于携带组织方式；补数量/空态，无新增预览只有一个关闭动作。 |
| 浏览器数据安全 | 实际打开存储说明与持久存储信息 | 解释真实存储限制，保留独立备份入口；本轮未请求原生持久权限。 |
| 通知与安装 | 实际打开启用方法与安装说明 | 提供平台能力入口与边界，不能承诺应用关闭后仍是系统闹钟；没有进行真实系统安装。 |
| 任务维护 | 0候选、实际归档1项及撤销、删除确认取消 | 工作区整理有价值；应显示符合条件数量并解释空状态，不等点击后才提示没有任务。 |
| 帮助、命令面板与诊断 | 实际打开说明、命令面板及下载本地诊断文件 | 提供学习和排查路径。修复旧toast盖住新弹窗标题；不自动发送任何报告。 |

URL/系统分享捕获与PWA快捷入口由源码和既有产品说明确认，本轮基线未在原生系统分享面板操作；候选中的实际可查入口另行记录。没有新增多人审批、账号、支付或跨设备同步。

## 本轮确认的主要缺口

1. **回顾口径错误：** 完成后归档使今日完成、连续天数与近期趋势归零；历史应包含本范围保留的归档完成记录。
2. **计划与重复衔接错误：** 生成的下一期被自动加入今天的手动计划。
3. **导入决策信息错误：** 切换合并后，仍展示替换覆盖的影响说明。
4. **反馈占据错误位置：** 旧通知可遮住新弹窗标题/关闭控件，本次弹窗反馈需要自己的流内位置。
5. **组织与操作语义缺口：** 批量移动项目缺失，单条/批量归档规则不一，同条件保存视图实际更新却没有说明，危险确认缺少对象。
6. **质感缺少统一角色：** 平灰遮罩、暗色亮浮雕边、菜单与母表面混在一起、双焦点框，以及不同选择动作形状相同。

## 视觉打磨的用途

固定导航与浮层采用有明确遮挡关系的玻璃层；内容表面保持稳定、可读。圆形完成控件表达执行，方形控件表达选择。强调色与亮暗模式独立，成功、警告、逾期和危险操作继续有固定语义。柱状图表达时间变化，项目数量列表支持具体操作。圆形/饼图是用户提供的审美建议，不是必须增加的控件；本轮不添加重复当前任务详情、容易被长期归档数量主导的构成饼图。

## 整改后的实际复核

- 从统计进入今天截止与已完成任务后，有独立“返回统计”。把唯一已完成任务归档，使当前列表变空，再返回原范围，仍显示近7日完成1项和已归档1项；不是恢复旧计数。趋势日期与每日数量均可见。
- 真实批量移动项目、空输入警告和撤销走通；最终对话框显示“已选择1个任务”。同条件保存视图显示“更新”并带原名称；删除显示对象和明确动作；稍后提醒留下具体时间和通知关闭状态。
- 真实导出JSON，检查合并模式全部跳过的0变更结果，下载替换前快照后确认替换，再检查当前→恢复点数量。最终手机反馈位于标题下方，不覆盖标题和关闭按钮；重复视图导入只有一个关闭动作。
- 四强调色和亮暗模式真实切换；320px英文深色表单、390px中文批量与导入、1440px桌面工作区已逐张检查。新的公开截图均为实际页面。页面层次有区分，完成与选择形状各有语义，没有为装饰删减功能。

初轮候选复查又发现星期标签被挤掉、统计下钻返程不清楚、批量移动缺少数量、警告沿用成功勾号、焦点叠加及手机通知旧样式覆盖。六项已集中修正并以全新资料复核。一次原候选页面reload仍受同版本开发缓存影响，已排除，未为此改动正常代码；发行版升级另按真实旧包验证。

定向保护进一步发现导入重组遗漏了已有差异组件，新增任务名称无法在确认前查看。已恢复到“文件检查与变更详情”中，并亲用含两项新任务的文件，核对新名称和当前替换范围后取消，原任务保留。这一遗漏如实保留首次失败记录，没有删去原有断言来获得通过。

## 证据和边界

本轮基线使用Linux Chromium、1440px桌面和390px模拟手机，中英文及亮暗。完整新截图与报告保留在本次工作区 `/workspace/design-research/task-tracer-craft-2026-10-25/` 的 `root-audit`、`task-audit`、`stats-audit`、`settings-audit` 与 `material-audit` 中。审查脚本的错误选择器/已关闭弹窗操作不作为产品缺陷。

真实手机/软键盘、原生通知投递、系统安装、持久存储授权、缩放与规模表现不因这些截图自动视为通过。数据事务、输入法事件与并发保护在候选稳定后按改动范围另做验证。
