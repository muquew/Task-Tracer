# Task Tracer — 静态发行包

本地优先的任务工作台，支持项目、日历、重复任务和备份，无需账号或任务服务器。

## 运行

- 完整解压后使用 HTTPS 部署，或启动可信本地服务：`python3 -m http.server 8080 --bind 127.0.0.1`。
- 保留 service worker、语言、图标和 `vercel.json` 等全部文件。直接以文件方式打开 `index.html` 不能提供完整 PWA 体验。
- 用同目录 `.zip.sha256` 校验压缩包；`integrity.json` 记录 23 个载荷哈希及构建信息。哈希不等于加密或发布者签名。

## 使用

- 顶部“添加任务”直接打开完整表单；旁边箭头用于快速记录。列表、日历、时间线和统计共享任务数据。
- “设置与数据”管理外观语言、备份迁移、提醒安装、任务维护和帮助；四套工作区主题均支持浅色与深色。
- 数据只存于当前浏览器配置。换设备、清站点数据或降级前，分别下载任务 JSON 与保存视图 JSON。
- 任务 JSON 可恢复受支持的任务字段，不包含视图、偏好和恢复历史；CSV 是报表，不能恢复任务。
- 本地恢复历史与任务共用浏览器存储，不能替代外部备份。确认文件已保存，再检查导入预览、选择合并或替换。
- 刷新前保存重要文字；未提交的快速记录和待恢复草稿可能只在当前页面内存中。
- 从“帮助与关于 → 检查更新”操作，先处理草稿，待更新准备好再刷新；升级后关闭旧窗口。
- 离线启动需先联网完成缓存。安装和提醒依赖浏览器与系统，应用关闭后不保证系统级准时投递。
