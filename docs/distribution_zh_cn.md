# Task Tracer 4.13.2 静态应用发行包

本压缩包包含浏览器应用、部署响应头配置、图标、翻译、第三方许可声明和 SHA-256 文件完整性清单，不包含账号服务、云同步或支付服务。

## 使用工作区

新工作区默认保持空白。“用示例了解功能”可加入三个有明确名称前缀、关闭提醒的普通任务，可编辑、删除或撤销；刷新空工作区不会自动补充示例。“设置与数据 → 帮助与关于 → 使用帮助与支持”先显示操作入口与快捷键，捕获、搜索、日期、备份、离线和隐私细则按需展开。“帮助与关于”也可直接查看诊断信息，存储受限时仍可使用。

从顶部“添加任务”直接打开完整表单；旁边“快速记录”箭头展开轻量输入，预览截止时间、项目与标签，“完整表单”可将其文字带入完整表单。已有未提交的快速记录文字时，主“添加任务”会接续内容；`Ctrl/Cmd + I` 保持独立新增。描述和子任务位于主表单，标签、提醒与重复规则在“更多设置”中按需展开。侧栏提供全部任务、手动选择的“今日计划”、项目和保存的视图，窄屏可用导航按钮展开侧栏。搜索、项目和状态筛选作用于完整工作区；“保存视图”记录当前搜索、筛选和视图，供从侧栏重新打开。

保存任务时会一并收纳子任务输入框中尚未点“＋”的文字。在列表、日历或时间线中，任务若被当前筛选、日历日期或已加载分页隐藏，成功提示中的“打开任务”可直接打开它，不自动改变这些条件。

新建完整表单与快速记录默认继承当前明确项目；无项目任务范围保持无项目，“全部项目”才默认 `Inbox`，快速记录中显式填写的 `/项目` 优先。在“今日计划”中创建会加入当前计划，不改变截止日期；已有计划任务但搜索／筛选无匹配时，可清除条件并留在计划。

桌面侧栏的品牌和列表／日历／时间线／统计保持顶部，“设置与数据”固定底部，中段滚动区容纳范围、全部项目和保存视图。手机视图导航保持底栏，打开抽屉会让当前范围可见。设置分为外观与语言、备份与迁移、提醒与安装、任务维护、帮助与关于五个面板；返回任务保留筛选和未提交的快速记录。任务维护展示全工作区已完成且未归档的数量，为零时禁用归档／删除。

从“设置与数据 → 外观与语言”选择四套完整的“工作区主题”预览：雾紫、海湾、松林、莓暮。原生单选项展示侧栏、工作区底面、页头和内容层，各主题还为字段、浮起菜单、文字、控件及选中状态提供各自的亮暗配色。外观“浅色／深色／跟随系统”和界面语言“简体中文／English”仍使用独立的原生下拉选择。跟随系统响应操作系统配色偏好；切换主题保留当前输入、任务与选择，不改写用户内容。

主题偏好保存在当前浏览器配置中，原有Iris／Ocean／Pine／Berry选择会沿用为对应的完整工作区主题；任务JSON备份仍不包含应用偏好。主题随本地应用提供，离线使用仍需遵循下文的首次缓存要求与浏览器限制。

任务左侧的完成控件用于标记状态。打开该任务的“任务操作”菜单，可按任务情况编辑、加入今日计划、稍后提醒、跳过本次重复、归档或删除；不适用的操作不会提供。顶部的撤销可恢复最近一次仍有效的任务操作；较新的并发更改可能使旧撤销不再可用。 最窄布局中，顶栏撤销使用图标并保留可访问名称。

悬停反馈或聚焦其中控件会暂停提示剩余时间，离开后接着计时；使用提示中的“撤销”后，焦点回到仍可用的任务控件。

单条与批量归档均可将尚未归档的任务移出日常列表，包括未完成任务，并保留完成状态。重复任务生成的新一期不会继承上一期手动选择的今日计划。稍后提醒的具体时间会持续显示；通知权限或应用设置未启用时，同时显示“通知未开启”。保存提醒时间不代表关闭应用后仍能保证投递。

统计首先提供逾期、今天截止和无日期待办三个任务入口，数量按当前项目与搜索计算，不使用任务状态下拉框；数量为零时入口禁用。进入任务或项目明细后，可用“返回统计”恢复来源视图，手动改变任务范围则结束此返回上下文。标明日期的近七日柱状趋势、今日完成数和连续天数包含本范围内仍保留的已归档完成记录；它们反映已保存的完成记录，不重建已删除任务的历史。“当前任务详情”按需展开。

未来7天日期索引和小月历会在完整日历视图中打开所选日期。窄屏可从“今天截止”摘要的“查看日程”入口打开月历。选择日期改变查看范围，不会重新安排任务的截止时间。“今日计划”是手动集合，与今天截止的任务保持独立。列表、日历、时间线和统计继续呈现同一份任务数据。

日历任务操作导致重绘后，焦点回原日程任务或日期。时间线在日期组内显示精简时钟与短状态，完整期限保留在可访问文字和悬停详情中，普通列表仍显示完整日期。分组或项目视图已提供项目上下文时省去重复徽标，跨项目搜索仍保留项目标识。

常用快捷键包括 `Ctrl/Cmd + I` 添加任务、`Ctrl/Cmd + K` 聚焦搜索、`Ctrl/Cmd + P` 打开命令面板。任务操作菜单支持方向键、Home、End 和 Escape；关闭弹窗后，焦点返回仍可用的发起控件。输入法组词时，快捷键不会接管文字输入。

## 部署与升级

请将所有文件一起部署到独立的 HTTPS 站点。Vercel 会应用 `vercel.json` 中的脚本哈希 CSP 等安全响应头；使用其他主机时需配置相同的响应头。 Vercel 配置还明确跳过依赖安装与构建，直接提供当前静态目录，无需在网站构建中运行 Python 或 npm。本地评估可在解压目录执行 `python3 -m http.server 8080`。直接双击打开 HTML 文件不是受支持的 PWA 安装方式。

任务与恢复历史保存在当前浏览器配置中。更换域名或设备、清理网站数据、升级应用之前，请导出备份。升级后先关闭旧版标签页，再打开新版应用。恢复历史不能应对浏览器配置或设备丢失。提醒受应用和浏览器生命周期影响，不能视为保证送达的系统闹钟。

本次界面更新保持数据库版本2、任务备份 JSON 2.4 和视图文件1.1，并兼容视图1.0导入。格式不变并不表示所有旧界面都能理解较新的偏好或视图范围，升级与降级仍需遵守下文的旧窗口说明。

## 任务、日期与大工作区

新设置或更改的截止时间使用当前设备时区。时钟跳变导致所填时间不存在时，会按跳变量向后顺延；同一时间出现两次时使用第一次，请核对实际显示的截止时间。未更改日期和时间的其他字段编辑会保留原时间点，包括原先已存的第二次重复时间。重复任务在任务保存的时区中推进日历日期，不受设备时区影响。

相对日期搜索、今日计划、逾期筛选和统计会在每分钟检查及页面重新可见时更新。弹窗、行内编辑、文本选择、拖动或已有批量选择期间可能暂缓刷新。后台计时器可能被浏览器挂起，这不是精确的后台定时服务。逾期率的分子为逾期进行中任务，分母为有截止日期的进行中任务；已完成、已归档和无截止日期任务不计入该分母。

输入法组词期间，Enter、Escape 和方向键用于文字输入。批量模式先显示 100 个任务，可继续“显示更多”。“全选匹配项”选择当前搜索、项目和状态范围内的全部任务，包括尚未显示的项目；选择数量表示实际操作范围。“更多操作 → 移动到项目”会显示选中数量，可选择已有项目或输入新项目名，移动支持撤销。翻页保留选择，范围变化后会移除新范围外的选择。较新的并发修改可能使撤销不再提供或被拒绝，避免覆盖较新数据。

普通及批量列表与时间线先显示 100 个匹配任务。日历无日期任务与选定日期详情也分别先显示 100 项，提供独立的“显示更多”，批量模式同样适用；计数与搜索仍覆盖全部任务。非批量模式的手动排序保留完整列表的渲染成本。

## 备份、导入与恢复

从“设置与数据 → 备份与迁移 → 恢复历史”可对照当前与目标任务数量，预览所选恢复点的任务名称与状态，先显示 100 项并保留完整计数。恢复按钮标明目标数量，确认后整体替换当前任务。“导出此恢复点”下载可导入的任务 JSON 2.4，空恢复点也可导出，不更新当前任务备份覆盖状态。“清空恢复历史”需要单独确认，只删除本地恢复点；历史变化后需检查刷新列表，再次确认。当前任务、视图、设置、下载文件与撤销不变。旧恢复点可能保留已删除任务的副本，后续任务写入会创建新恢复点。

发起任务 JSON 下载后，应用在当前浏览器记录供下载快照的任务版本与导出日期；这是本地覆盖记录，并非任务 JSON 新增字段。发起下载不等于文件已经保存或仍被保留，请检查实际文件并另存副本。任务变化或只有日期的旧导出记录会提示需要再次导出，不能据此认定当前任务已覆盖。每次 JSON 或 CSV 导出读取一致的任务快照，不会刷新可见任务列表。

导入预览先明确“合并”或“替换”模式：合并显示实际新增、替换本地、跳过文件项、保留当前任务和最终总数；替换对照当前全部任务与文件目标数量。切换模式或冲突选项会更新数量和动作名称，已通过的文件检查可按需展开。替换前必须下载导入前快照；合并更改前会先保留当前任务的本地恢复点。本地恢复与任务共享浏览器存储，不能替代独立备份。

JSON 备份可恢复受支持的任务字段，包括子任务、项目、标签、计划、提醒及今日计划；不包含保存的视图、应用设置和恢复历史。可通过“设置与数据 → 备份与迁移 → 迁移保存的视图”（位于“其他数据工具”）另存视图 JSON，新导出为 1.1，导入也兼容 1.0；最多 12 个视图且不超过 1 MiB。导入预览展示新增、重复和容量跳过数量，保留已有视图，不会为腾出空间删除它们；另一窗口更改视图后需检查更新预览再确认。视图文件可能包含私密搜索词、项目名和标签。任务文件读取可取消；导入预览期间数据变化后需重新检查并完成安全确认。合并冲突控件按每批 100 项加载，批量选项作用于全部同名任务，更改后会重置逐项选择。CSV 同样位于“其他数据工具”，用于全部任务的表格报表，公式前缀会添加单引号；不能导入恢复，也不计为备份。

## 未保存内容与存储故障

修改任务表单后，通过取消、关闭图标、Escape 或点击遮罩退出时，会询问继续编辑还是放弃更改。快速添加中有文字、任务表单有未保存更改或仍有待恢复草稿时，会请求浏览器离页提醒，该提醒仍受浏览器规则限制。草稿不会自动写入持久存储或服务器，离开前请保存或复制重要文字。 待收纳的子任务文字也纳入未保存更改确认与草稿恢复。

存储故障时若快速添加中仍有文字，输入框会保持只读，可选中复制。有快速添加文字或待恢复表单时，“重试”在原页面重连存储，保留原文与捕获的来源信息。恢复后请自行重新提交，“重试”不会重放添加。快速添加文字仅在页面内存中，不包含在完整表单的草稿下载里；刷新或关闭前请复制到应用之外，崩溃仍可能丢失。

存储故障中断已修改的表单时，提示栏将草稿仅保留在当前页面内存。“下载未保存草稿”将全部待恢复表单另存为 `task-draft` JSON 供查阅，不是可导入的任务备份；请检查文件确实已保存。有待恢复草稿时，“重试”在原页面重连存储；存储可用后，“恢复编辑”打开下一份草稿，仍遵守过期编辑检查，已有表单需先处理完。“放弃下一份草稿”需要确认。刷新、关闭或崩溃会丢失内存草稿。草稿文件可能含私密未保存文字与被编辑任务的原记录，分享前请检查。

## 保存的视图与旧界面

在 4.7 或更新版本中修改保存视图前，请关闭或刷新所有旧版标签页与独立应用窗口：4.7 之前的版本可能将类型化范围对象当成“全部项目”，再次保存时还会写回该解释。降级前保留视图 1.1 导出文件；旧应用不能导入，需要回到 4.7 或更新版本恢复视图。任务与数据库格式不变，不代表新视图配置兼容旧界面。

项目范围会区分名为 `all`、`__none__` 的真实项目、“全部项目”和无项目任务；保存的项目暂时不存在时保持空结果。最多可保存 12 个不同条件的视图。满额后新增会保留原有视图与名称草稿。保存相同搜索、筛选和布局时，会打开“更新已保存的视图”，预填已有名称，并通过“更新视图”保留原入口。

保存视图的 × 会先显示带有准确视图名称的确认，默认聚焦“取消”。明确确认后才删除所选视图，任务不变。视图删除无法撤销，需要保留时请先导出视图文件。

## 离线使用与诊断

离线启动需先完成首次应用外壳缓存。HTML 内含匹配版本的语言数据，可在外部语言请求失败时使用，但不能替代其他必需文件的缓存。旧窗口仍使用各自已安装的 worker 策略；请将文件整包部署，刷新前保存草稿，升级后关闭旧窗口。清理网站数据也会移除离线副本。

从“设置与数据 → 帮助与关于 → 检查更新”主动检查并查看状态。更新准备好后才提供“刷新更新”；未提交的快速记录、未保存表单和待恢复草稿需先处理，保存中或任务操作未结束时也会阻止刷新。应用等待已准备好的worker接管，不通过固定延时强制重载。离线、不支持或检查失败会各自说明，可在条件恢复后重试。

“设置与数据 → 帮助与关于 → 查看诊断信息”提供本地 JSON 的完整预览，再由你选择下载；“使用帮助与支持”中也有同一入口。内容包括应用与浏览器版本、能力、权限状态和存储估计，不包含任务内容、保存的视图、应用设置、URL 或原始错误消息；不会自动上传，诊断文件不能用作任务备份。
