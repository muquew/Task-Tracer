# Task Tracer 静态应用发行包

本压缩包包含浏览器应用、部署响应头配置、图标、翻译和 SHA-256 文件完整性清单，不包含账号服务、云同步或支付服务。

新工作区默认保持空白。可选的“添加 3 个示例任务”操作会创建有明确名称前缀、关闭提醒的普通任务，可编辑、删除或撤销；刷新空工作区不会自动补充示例。菜单和页脚的“使用帮助”提供捕获、搜索、快捷键和浏览器限制说明，存储受限时仍可查看。

请将所有文件一起部署到独立的 HTTPS 站点。Vercel 会应用 `vercel.json` 中的脚本哈希 CSP 等安全响应头；使用其他主机时需配置相同的响应头。 Vercel 配置还明确跳过依赖安装与构建，直接提供当前静态目录，无需在网站构建中运行 Python 或 npm。本地评估可在解压目录执行 `python3 -m http.server 8080`。直接双击打开 HTML 文件不是受支持的 PWA 安装方式。

任务与恢复历史保存在当前浏览器配置中。更换域名或设备、清理网站数据、升级应用之前，请导出备份。升级后先关闭旧版标签页，再打开新版应用。恢复历史不能应对浏览器配置或设备丢失。提醒受应用和浏览器生命周期影响，不能视为保证送达的系统闹钟。

新设置或更改的截止时间使用当前设备时区。时钟跳变导致所填时间不存在时，会按跳变量向后顺延；同一时间出现两次时使用第一次，请核对实际显示的截止时间。未更改日期和时间的其他字段编辑会保留原时间点，包括原先已存的第二次重复时间。重复任务在任务保存的时区中推进日历日期，不受设备时区影响。

相对日期搜索、今日计划、逾期筛选和统计会在每分钟检查及页面重新可见时更新。弹窗、行内编辑、文本选择、拖动或已有批量选择期间可能暂缓刷新。后台计时器可能被浏览器挂起，这不是精确的后台定时服务。逾期率的分子为逾期进行中任务，分母为有截止日期的进行中任务；已完成、已归档和无截止日期任务不计入该分母。

恢复历史可预览所选恢复点的任务名称与状态，先显示 100 项并保留完整计数。“导出此恢复点”下载可导入的任务 JSON 2.4，空恢复点也可导出，不更新当前任务备份覆盖状态。“清空恢复历史”需要单独确认，只删除本地恢复点；历史变化后需检查刷新列表，再次确认。当前任务、视图、设置、下载文件与撤销不变。旧恢复点可能保留已删除任务的副本，后续任务写入会创建新恢复点。

输入法组词期间，Enter、Escape 和方向键用于文字输入。批量模式先显示 100 个任务，可继续“显示更多”。“全选匹配项”选择当前搜索、项目和状态范围内的全部任务，包括尚未显示的项目；选择数量表示实际操作范围。翻页保留选择，范围变化后会移除新范围外的选择。较新的并发修改可能使撤销不再提供或被拒绝，避免覆盖较新数据。

普通及批量列表与时间线先显示 100 个匹配任务。日历无日期任务与选定日期详情也分别先显示 100 项，提供独立的“显示更多”，批量模式同样适用；计数与搜索仍覆盖全部任务。非批量模式的手动排序保留完整列表的渲染成本。

发起任务 JSON 下载后，应用在当前浏览器记录供下载快照的任务版本与导出日期；这是本地覆盖记录，并非任务 JSON 新增字段。发起下载不等于文件已经保存或仍被保留，请检查实际文件并另存副本。任务变化或只有日期的旧导出记录会提示需要再次导出，不能据此认定当前任务已覆盖。每次 JSON 或 CSV 导出读取一致的任务快照，不会刷新可见任务列表。

JSON 备份可恢复受支持的任务字段，包括子任务、项目、标签、计划、提醒及今日计划；不包含智能视图、应用设置和恢复历史。可通过“菜单 → 迁移保存的视图”另存视图 JSON，新导出为 1.1，导入也兼容 1.0；最多 12 个视图且不超过 1 MiB。导入预览展示新增、重复和容量跳过数量，保留已有视图，不会为腾出空间删除它们；另一窗口更改视图后需检查更新预览再确认。视图文件可能包含私密搜索词、项目名和标签。任务文件读取可取消；导入预览期间数据变化后需重新检查并完成安全确认。合并冲突控件按每批 100 项加载，批量选项作用于全部同名任务，更改后会重置逐项选择。CSV 用于全部任务的表格报表，公式前缀会添加单引号；不能导入恢复，也不计为备份。

修改任务表单后，通过取消、关闭图标、Escape 或点击遮罩退出时，会询问继续编辑还是放弃更改。快速添加中有文字、任务表单有未保存更改或仍有待恢复草稿时，会请求浏览器离页提醒，该提醒仍受浏览器规则限制。草稿不会自动写入持久存储或服务器，离开前请保存或复制重要文字。

存储故障时若快速添加中仍有文字，输入框会保持只读，可选中复制。有快速添加文字或待恢复表单时，“重试”在原页面重连存储，保留原文与捕获的来源信息。恢复后请自行重新提交，“重试”不会重放添加。快速添加文字仅在页面内存中，不包含在完整表单的草稿下载里；刷新或关闭前请复制到应用之外，崩溃仍可能丢失。

存储故障中断已修改的表单时，提示栏将草稿仅保留在当前页面内存。“下载未保存草稿”将全部待恢复表单另存为 `task-draft` JSON 供查阅，不是可导入的任务备份；请检查文件确实已保存。有待恢复草稿时，“重试”在原页面重连存储；存储可用后，“恢复编辑”打开下一份草稿，仍遵守过期编辑检查，已有表单需先处理完。“放弃下一份草稿”需要确认。刷新、关闭或崩溃会丢失内存草稿。草稿文件可能含私密未保存文字与被编辑任务的原记录，分享前请检查。

在 4.7 或更新版本中修改保存视图前，请关闭或刷新所有旧版标签页与独立应用窗口：4.7 之前的版本可能将类型化范围对象当成“全部项目”，再次保存时还会写回该解释。降级前保留视图 1.1 导出文件；旧应用不能导入，需要回到 4.7 或更新版本恢复视图。任务与数据库格式不变，不代表新视图配置兼容旧界面。

项目范围会区分名为 `all`、`__none__` 的真实项目、“全部项目”和无项目任务；保存的项目暂时不存在时保持空结果。最多可保存 12 个不同条件的视图。满额后新增会保留原有视图与名称草稿；相同搜索、筛选和布局仍可更新对应视图。

保存视图的 × 会先显示带有准确视图名称的确认，默认聚焦“取消”。明确确认后才删除所选视图，任务不变。视图删除无法撤销，需要保留时请先导出视图文件。

离线启动需先完成首次应用外壳缓存。HTML 内含匹配版本的语言数据，可在外部语言请求失败时使用，但不能替代其他必需文件的缓存。旧窗口仍使用各自已安装的 worker 策略；请将文件整包部署，刷新前保存草稿，升级后关闭旧窗口。清理网站数据也会移除离线副本。

使用帮助提供本地诊断 JSON 的完整预览，再由你选择下载。内容包括应用与浏览器版本、能力、权限状态和存储估计，不包含任务内容、智能视图、应用设置、URL 或原始错误消息；不会自动上传，诊断文件不能用作任务备份。

解压前请使用同目录的 `.zip.sha256` 校验压缩包。构建工具明确列出 22 个源文件，再生成 `integrity.json`，不会递归打包整个资源目录。`integrity.json` 记录各文件的哈希、源代码提交，以及是否从有改动的工作区构建。哈希可检测意外改动，但不等同于发布者签名或商业授权。
