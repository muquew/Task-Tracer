# Security

- Security fixes target the latest published version.
- Report vulnerabilities privately through this repository's **Security → Report a vulnerability**, when available.
- If private reporting is unavailable, request a private channel in an issue without disclosing the vulnerability.
- Include the affected version, browser/OS, impact and a minimal reproduction using synthetic tasks.
- Use [Issues](https://github.com/muquew/Task-Tracer/issues/new/choose) for ordinary bugs and suggestions.

Never publish personal task backups, saved views, drafts, credentials or unredacted diagnostic files.
